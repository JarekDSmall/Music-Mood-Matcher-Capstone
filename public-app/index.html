    How this version works

    The original Music Mood Matcher was a React, Express, and MongoDB capstone that used Spotify listening data. This public adaptation matches editorial mood tags and energy preferences from an included catalog. The public flow runs in your browser; no account or server is required.

    Optional Spotify export uses authorization code with PKCE. Your Spotify password and client secret are never requested by this app. The access token stays in this tab’s session storage until it expires or you disconnect. Playlist data is saved locally only when you choose Save.
